# POOCH v0.1.0

Release date: 2026-07-08

## Overview

This is the initial public release of POOCH (Parent Of Origin Classification Of Haplotypes), a Snakemake-based workflow for phasing-aware methylation analysis and chromosome-level parent-of-origin prediction from long-read sequencing data.

## Highlights

- End-to-end workflow from read input to chromosome-level parent-of-origin prediction.
- Supports ONT and HiFi methylation calling paths.
- Supports multiple entry modes so users can start from FASTQ, BAM, or methylation BED files.
- Supports personalized diploid genomes and split haplotype FASTA inputs.
- Supports Winnowmap2 (default) and Minimap2 for alignment.

## Included Workflow Steps

1. Input validation and methylation-tag checks.
2. Personalized genome preparation (or split-FA usage).
3. Read alignment to personalized diploid reference.
4. Chain generation and coordinate liftover to CHM13.
5. Methylation calling and haplotype-specific methylation split.
6. Chromosome assignment and parent-of-origin prediction.

## Command-Line Interface

The `pooch` wrapper is included with:

- Validated required arguments and input-mode checks.
- `--aligner` selection (`Winnowmap2` or `Minimap2`).
- `--step` support for running specific Snakemake targets.
- `--dry-run` and `--touch` passthrough options.
- `--snakeopts` passthrough for advanced Snakemake usage.

Version string for this release: `0.1.0`.

## Primary Outputs

- `OUTDIR/prediction/SAMPLE.chroms.txt`
- `OUTDIR/prediction/SAMPLE.predict.out`
